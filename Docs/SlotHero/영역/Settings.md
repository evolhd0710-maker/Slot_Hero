# Slot Hero 설정 화면 코드

인게임 화면 기획서 v0.2 / 07 설정 화면 을 옮긴 코드다.

설정 기획서가 따로 없어 어떤 항목이 들어가는지는 정해져 있지 않다.
화면 기획서가 정한 것은 탭으로 나눈다는 것과 이름은 왼쪽 값은 오른쪽이라는 배치까지다.
그래서 항목을 코드에 박지 않고 설정 에셋에 적어 두고 화면이 그것을 읽어 그린다.

저장소를 받으면 이 `Settings` 폴더를 통째로 `Assets/Scripts/Settings`로 옮기면 된다.

## 파일 구성

```
Settings/
  Runtime/
    Data/
      SettingDefinition.cs        항목 하나의 정의와 값 다루기. SettingKind 도 여기 있다
      SettingsValues.cs           지금 값. 저장에 그대로 실린다
    Config/
      SettingsCatalogConfig.cs    탭과 항목 목록. ScriptableObject
      SettingsLayoutConfig.cs     화면 자리와 크기. ScriptableObject
      SettingsVisualConfig.cs     색과 글자. ScriptableObject
    UI/
      SettingsTabView.cs          분류 탭 하나
      SettingsRowView.cs          설정 항목 한 줄. 소리 크기 줄의 막대와 음소거 버튼도 여기 있다
      SettingsOptionView.cs       드롭다운 목록의 선택지 한 칸
      SettingsScreenView.cs       화면 배치와 표시
      SettingsScreenController.cs 탭 고르기, 값 바꾸기, 기본값 복원, 닫기
```

## 기획서 대응표

| 기획서 | 코드 |
| --- | --- |
| 제목 · 화면 왼쪽 위에 "설정" | `TitlePosition`, `SettingsVisualConfig.TitleText` |
| 분류 탭 · 설정을 여러 탭으로 구분 | `SettingsCatalogConfig.Tabs`, `SettingsTabView` |
| 선택된 탭만 진하게 표시 | `GetTabColor` 가 고른 탭에 `SelectedTabColor` 를 쓴다 |
| 설정 목록 · 선택된 탭의 항목을 세로로 | `ShowItems`, `GetItemLocalPosition` |
| 항목 이름을 왼쪽, 현재 값은 오른쪽 | `SettingsRowView.PlaceParts` |
| 기본값 복원 · 좌하단 | `RestorePosition` |
| 기본값 복원 · 기본값 복원 확인 팝업을 거친다 | `RestoreRequested` 이벤트로 알리고, 흐름(`GameFlowController.ShowSettingsRestoreConfirm`)이 팝업을 띄운 뒤 `RestoreDefaults` 를 부른다 |
| 닫기 · 우하단, 이전 화면으로 | `ClosePosition`, `Closed` 이벤트 |

## 자리와 크기

와이어프레임에서 잰 값을 10 단위로 옮긴 것이다. 괄호 안이 실측값이다.

| 항목 | 자리와 크기 |
| --- | --- |
| 제목 | x 120, y 80, 580 × 90 (115 · 76 · 576 × 86) |
| 분류 탭 칸 | x 120, y 210, 380 × 680 (115 · 205 · 384 × 680) |
| 탭 하나 | x 140, y 230부터 100 간격, 350 × 90 (131 · 225 · 352 × 88) |
| 설정 목록 칸 | x 560, y 210, 1240 × 680 (557 · 205 · 1248 × 680) |
| 항목 하나 | x 600, y 260부터 90 간격, 1160 × 70 (595 · 259 · 1153 × 65) |
| 기본값 복원 | x 120, y 930, 360 × 90 (115 · 929 · 365 × 86) |
| 닫기 | x 1450, y 930, 350 × 90 (1459 · 929 · 346 × 86) |

자리가 잘 맞물린다.

- 두 칸 사이가 60으로 떨어진다
- 목록 칸의 오른쪽 끝이 1800이라 왼쪽 여백 120과 대칭이다
- 닫기의 오른쪽 끝도 1800으로 목록 칸과 같다
- 항목 폭 1160은 목록 칸에서 좌우 여백 40씩을 뺀 값과 정확히 같다

색은 다음과 같다.

| 자리 | 색 |
| --- | --- |
| 뒤 화면 | 검정 50퍼센트 |
| 제목 칸, 두 큰 칸, 아래 버튼 | `#D9D9D9` |
| 고르지 않은 탭, 항목 칸 | `#F2F0EC` |
| 고른 탭 | `#4A443C` |
| 고른 탭 글자 | `#FFFFFF` |

글자 크기는 04 화면 공통 규칙 의 텍스트 표를 따라
제목 40픽셀 굵게, 탭과 아래 버튼 30픽셀 굵게, 항목 이름과 값 26픽셀 굵게다.

## 설정 항목을 적는 법

항목은 `SettingsCatalogConfig` 에 적는다. 값을 다루는 방식은 세 가지다.

- **고르는 항목** 정해진 선택지 중 하나를 고른다. 칸을 누르면 다음 값으로 넘어간다.
  켜고 끄는 항목도 선택지 두 개인 고르는 항목으로 둔다
- **드롭다운 항목** 값은 고르는 항목과 같다. 칸을 누르면 선택지 목록이 줄 아래로 펼쳐진다
- **수치 항목** 줄 가운데의 막대를 끈다. 소리 크기가 이것이다.
  `Volume` 으로 만들면 0 ~ 100 을 1 씩 움직이고 오른쪽 끝에 음소거 버튼이 붙는다

```csharp
SettingDefinition.Dropdown("language", "언어", 0, "한국어", "English");
SettingDefinition.Choice("screenMode", "창 모드", 1, "창", "전체 화면", "테두리 없는 창");
SettingDefinition.Toggle("autoSaveNotice", "자동 저장", true, "꺼짐", "켜짐");
SettingDefinition.Choice("presentationSpeed", "연출 속도", 0, "보통", "빠름", "스킵");
SettingDefinition.Volume("bgmVolume", "배경음", 100f);
```

지금 들어 있는 항목은 다음과 같다. 2026년 10월 5일에 원재가 정한 것을 반영했다.

| 탭 | 항목 | 선택지와 기본값 |
| --- | --- | --- |
| 일반 | 언어 | 드롭다운. 한국어 / English. 기본 한국어. **기본값 복원에서 빠진다** |
| 일반 | 창 모드 | 창 / 전체 화면 / 테두리 없는 창. 기본 전체 화면. **기본값 복원에서 빠진다** |
| 일반 | 자동 저장 | 꺼짐 / 켜짐. 기본 켜짐 |
| 일반 | 연출 속도 | 보통 / 빠름 / 스킵. 기본 보통 |
| 사운드 | 전체, 배경음, 환경음, 효과음 | 0 ~ 100 막대와 음소거 버튼. 기본 100, 음소거 꺼짐 |

그래픽과 조작 탭은 비어 있다.

**목록의 정본은 코드다.** `CreateDefaultConfigs` 가 돌 때마다 에셋 안의 목록을 코드의 목록으로 갈아 끼운다.
에셋에서 손으로 고친 것은 남지 않는다. 이벤트 각본과 같은 방식이다.

연출 속도는 선택지 차례가 바뀌어 식별자를 `effectSpeed` 에서 `presentationSpeed` 로 바꿨다.
저장에 남은 옛 값은 `Open` 이 버리고 새 기본값으로 시작한다.

값은 모두 실수 하나로 다룬다. 고르는 항목은 몇 번째를 골랐는지, 수치 항목은 그 값 자체다.
저장에 실으려면 형태가 하나여야 하기 때문이다.

**음소거는 소리 크기와 따로 저장한다.** 식별자는 소리 크기 식별자 뒤에 `Mute` 를 붙인 것이다 (`bgmVolumeMute`).
켜고 끄는 항목이라 0 이면 꺼짐, 1 이면 켜짐이다. 크기를 건드리지 않으므로 음소거를 풀면 앞의 크기로 돌아간다.
줄로는 나오지 않고 그 소리 크기 줄의 버튼으로만 나온다. `CollectAllItems` 와 `FindItem` 은 음소거 값도 함께 다룬다.
그래서 기본값 복원이 음소거도 끈다.

## 기본값 복원

**기본값은 항목마다 적은 `DefaultValue` 다.** 처음 켰을 때의 값과 기본값 복원으로 돌아갈 값이 같다.
위 표의 "기본" 이 그것이다.

**해상도와 창 모드처럼 화면에 맞춰 고른 값과 언어는 되돌리지 않는다.** 2026년 10월 8일 원재가 정했다.
되돌리면 화면이나 읽던 글이 갑자기 바뀌어 다시 맞춰야 하기 때문이다.
그런 항목은 `KeptOnRestore()` 를 붙여 적는다. 지금은 언어와 창 모드 둘이다. 해상도 항목이 생기면 그것도 붙인다.

```csharp
SettingDefinition.Choice("screenMode", "창 모드", 1, "창", "전체 화면", "테두리 없는 창")
    .KeptOnRestore();
```

음소거는 제 소리 크기 항목을 따른다. 소리 크기가 되돌려지면 음소거도 꺼진다.

버튼을 누르면 확인 팝업이 뜬다. 제목은 "기본값으로 되돌리시겠습니까?", 버튼은 취소 / 되돌리기다.
본문 끝에 "그대로 두는 항목: 언어, 창 모드" 처럼 되돌리지 않는 항목을 적는다.
팝업이 떠 있는 동안 설정 화면은 ESC 를 받지 않는다(`InputBlocked`). 받으면 팝업 아래에서 설정이 먼저 닫힌다.

**2026년 10월 8일까지 게임에서는 이 버튼이 아무 일도 하지 않았다.**
`RestoreRequested` 를 받는 곳이 확인용 씬의 도우미뿐이었고,
게임 씬 검사는 버튼을 누르지 않고 `RestoreDefaults` 를 직접 불러 통과했다.
지금은 흐름이 받고, 게임 씬 검사가 진짜 버튼을 눌러 팝업, 취소, 되돌리기, 언어와 창 모드 유지, 저장까지 본다.

## 붙이는 법

### 1. 설정 에셋을 만든다

프로젝트 창에서 우클릭 후 `Create > Slot Hero > 설정`에서 세 개를 만든다.

- 설정 목록 (`SettingsCatalogConfig`)
- 설정 화면 자리 설정 (`SettingsLayoutConfig`)
- 설정 화면 표시 설정 (`SettingsVisualConfig`)

### 2. 씬을 만든다

```
SettingsScreen             SettingsScreenController, 화면 루트
  Dim                      Image · 뒤 화면을 덮는 막
  TitlePanel               Image
    TitleLabel             TMP_Text
  TabPanel                 Image
    TabLayer               빈 RectTransform. 탭이 여기 아래에 만들어진다
  ListPanel                Image
    ListScroll             ScrollRect · 세로만 켠다
      ListViewport         Mask 또는 RectMask2D
        ListContent        항목이 여기 아래에 만들어진다
  RestorePanel             Image + Button
    RestoreLabel           TMP_Text
  ClosePanel               Image + Button
    CloseLabel             TMP_Text
  DropdownLayer            맨 마지막 자식. 평소에는 꺼져 있다
    DropdownBlocker        투명 Image + Button. 화면 전체를 덮어 바깥을 누르면 접는다
    DropdownPanel          Image. 선택지가 여기 아래에 만들어진다
```

탭 프리팹은 루트에 `SettingsTabView` + `Button` + 배경 `Image`, 자식에 `TMP_Text`.
항목 프리팹은 루트에 `SettingsRowView` + `Button` + 배경 `Image`,
자식에 이름 `TMP_Text`, 값 `TMP_Text`, 막대 `Slider`, 음소거 `Button`.
막대와 음소거 버튼은 꺼 둔 채로 넣고, 줄이 소리 크기 항목일 때만 줄이 켠다.
선택지 프리팹은 탭 프리팹과 구성이 같고 스크립트만 `SettingsOptionView` 다.

```
막대 구성
Slider                     Slider · 손잡이 크기만큼 높이를 잡는다
  Track                    Image · 막대 바탕. 칸 가운데에 얇게
  FillArea                 막대와 같은 자리
    Fill                   Image · 찬 부분. Slider.fillRect
  HandleArea               손잡이 폭의 반만큼 양쪽을 줄인 자리
    Handle                 Image · Slider.handleRect
```

줄은 목록 칸 왼쪽 위를 기준으로 `ListContent` 안에 놓는다. 내용은 창 왼쪽 위에 붙여 둔다.
예전에는 줄을 화면 좌표로 놓고 내용의 원점을 화면 왼쪽 위로 끌어 올렸는데,
플레이 모드에서는 `ScrollRect` 가 매 프레임 내용을 창 안으로 끌어 넣어 줄이 그만큼 아래로 밀렸다.
편집 모드에서 뽑은 그림에서는 스크롤이 돌지 않아 멀쩡해 보였다.

자리는 `SettingsScreenView` 를 우클릭해 `기획서 자리로 맞추기` 를 누르면 잡힌다.

### 3. 호출

```csharp
// 설정 화면을 연다. 저장해 둔 값을 넘긴다
settings.Open(savedSettingsValues);

// 값이 바뀌면 그 값을 쓰는 쪽이 받아 적용한다
settings.ValueChanged += (definition, value) =>
{
    if (definition.Id == "autoSaveNotice")
    {
        hud.SetAutoSaveNoticeEnabled(value >= 0.5f);
    }
};

// 기본값 복원은 확인 팝업을 거친다
settings.RestoreRequested += () =>
{
    PopupSpec spec = PopupSpec.Confirm(
        "기본값으로 되돌리시겠습니까?",
        "모든 설정이 처음 값으로 돌아갑니다.\n그대로 두는 항목: 언어, 창 모드",
        "취소",
        "되돌리기",
        confirmIsDangerous: true);

    popup.Show(spec, buttonId =>
    {
        if (buttonId == "confirm")
        {
            settings.RestoreDefaults();
        }
    });
};

// 닫으면 이전 화면으로 돌려보낸다
settings.Closed += () => previousScreen.Open();

// 저장할 때
SettingsValues values = settings.Values;
```

`SettingsValues` 는 `[Serializable]` 이라 `JsonUtility` 로 그대로 직렬화된다.
저장 시스템 기획서의 "설정은 기기당 1"에 해당하므로 프로필과 따로 저장한다.

`Open` 은 저장에 없던 새 항목을 기본값으로 채우고
정의에서 사라진 항목의 값을 버린다. 항목을 더하거나 빼도 저장이 깨지지 않는다.

## 검증 결과

유니티 없이 순수 로직만 따로 빌드해 151건을 확인했고 전부 통과했다.

- 기본값 복원이 연출 속도, 소리 크기, 음소거를 되돌리고 언어와 창 모드는 고른 값 그대로 둔다.
  바뀐 항목만 알리고, 확인 팝업에 적을 이름은 언어와 창 모드다
- 고르는 항목이 마지막 다음에 처음으로 돌아가고 수치 항목은 끝에서 멈춘다
- 언어는 드롭다운, 창 모드와 연출 속도는 선택지 셋, 사운드 네 항목은 0 ~ 100 막대에 음소거가 붙는다
- 음소거 값도 식별자로 찾히고 기본값 복원으로 꺼진다
- 소리 크기 줄에 이름, 막대, 숫자, 음소거 버튼이 한 줄에 들어간다 (막대 길이 400 이상)
- 값이 범위를 넘으면 잘리고, 같은 값을 다시 담으면 바뀌지 않았다고 알린다
- 저장에 없던 항목은 기본값으로 채워지고 정의에 없는 값은 버려진다
- 탭 넷의 이름과 일반 탭 네 항목의 이름, 기본값이 와이어프레임과 같다
  (한국어, 전체 화면, 켜짐, 보통)
- 탭과 항목 자리가 전부 10 단위로 떨어진다
  (탭 x 140 · y 230부터 100 간격, 항목 x 600 · y 260부터 90 간격)
- 칸 안에 탭도 항목도 여섯까지 들어가고 일곱부터 스크롤이 필요하다
- 닫기의 오른쪽 끝이 설정 목록 칸의 오른쪽 끝과 맞는다
- 고른 탭이 더 진하고 글자는 더 밝다

유니티에서 게임 씬을 굴리며 실제 버튼을 눌러 본 것은 다음과 같다.

- 스크롤 창을 한 번 돌린 뒤에도 첫 줄이 목록 칸 맨 위에서 50 아래에 붙어 있다
- 줄에 마우스를 올려도 24 픽셀까지만 커지고 벗어나면 제 크기로 돌아온다
- 언어 줄을 누르면 목록이 줄 오른쪽 아래에 펼쳐지고, 고르면 값이 바뀌고 접힌다.
  바깥을 누르거나, 같은 줄을 다시 누르거나, 탭을 바꿔도 접힌다
- 창 모드는 전체 화면 → 테두리 없는 창 → 창, 연출 속도는 보통 → 빠름 → 스킵으로 넘어간다
- 막대를 40 으로 옮기면 값과 숫자가 40 이 되고, 음소거는 눌러 켜고 다시 눌러 끈다. 크기는 그대로다
- 기본값 복원 버튼을 누르면 확인 팝업이 뜨고 본문에 언어와 창 모드가 적힌다. 팝업이 떠 있는 동안 설정은 ESC 를 받지 않는다.
  취소하면 아무것도 안 바뀌고, 되돌리기를 누르면 언어와 창 모드만 남기고 되돌린 뒤 기기 설정에 저장한다

## 기획서끼리 어긋나는 곳

**기본값 복원이 무엇을 되돌리는지 두 곳이 다르다.**
07 설정 화면 은 "전체 설정 값을 되돌린다"이고
08 화면 팝업 의 확인 단계 표는 "지금 탭의 값이 모두 되돌아간다는 안내"다.

07장을 따라 전체를 되돌리게 했다.
지금 탭만 되돌리려면 `SettingsScreenController` 의 `_restoreCurrentTabOnly` 를 켠다.

## 기획서에 없어 내가 정한 부분

확인이 필요하면 알려 주면 고친다.

1. **값을 고르는 방법** 기획서는 값이 오른쪽에 있다는 것까지만 정했다.
   고르는 항목은 칸을 누르면 다음 값으로 넘어가고 오른쪽 버튼으로 누르면 앞 값으로 돌아간다.
   언어를 드롭다운으로, 소리 크기를 막대와 음소거 버튼으로 하는 것은 원재가 정했다.
2. **값을 다루는 세 방식** 고르는 항목, 드롭다운 항목, 수치 항목으로 나눴다.
   켜고 끄는 항목은 선택지가 둘인 고르는 항목이다.
3. **드롭다운 모양** 줄 오른쪽 끝에 맞춰 줄 바로 아래로 펼친다. 선택지 한 칸은 300 × 60 이다.
   지금 고른 선택지는 고른 탭처럼 진하게 칠한다. 값 뒤에 `▼` 를 붙여 펼칠 수 있다는 것을 알린다.
   펼친 동안 ESC 는 목록만 접고, 한 번 더 누르면 화면을 닫는다.
4. **소리 크기 줄 모양** 이름 뒤 x 300 부터 막대, 숫자 칸 80, 음소거 버튼 130 × 50 이 차례로 붙고 사이는 20 이다.
   음소거가 켜지면 버튼이 고른 탭 색으로 진해지고 막대가 40 퍼센트로 흐려진다.
5. **소리 크기 기본값** 기획서에 없어 모두 100 으로 두었다.
6. **값을 적는 시점** 확인 버튼 없이 닫기만 있으므로 바꾸는 즉시 적는다.
   실제로 그 값을 쓰는 일은 `ValueChanged` 를 받는 쪽이 한다.
   막대를 끄는 동안에는 값이 바뀔 때마다 알린다.
7. **항목이 많을 때** 목록 칸보다 많으면 그 안에서만 세로로 스크롤한다.
   지금 칸 크기로 여섯까지 들어간다.
8. **단축키** 기획서에 설정 화면의 단축키가 없다.
   다른 화면을 따라 ESC 로도 닫게 했다.
9. **비어 있는 탭** 그래픽, 조작 탭에 항목을 넣지 않았다.
   무엇이 들어가는지 정해지지 않았기 때문이다. 지금은 빈 목록이 나온다.

## 이 코드에 없는 것

- 각 설정이 실제로 하는 일. 해상도 바꾸기, 소리 크기 적용, 조작 바꾸기는
  `ValueChanged` 를 받는 쪽이 한다
- 그래픽 · 조작 탭의 항목 목록. 정해지면 `SettingsCatalogConfig` 에 적는다
- 설정을 파일로 쓰고 읽는 일. 저장 시스템 기획서 소관이다
- 기본값 복원 확인 팝업. `Popup` 폴더의 공통 틀로 띄운다
