# Slot Hero 영어 번역 코드

인게임 화면 기획서 07 설정 화면의 일반 탭 "언어" 를 English 로 고르면 게임 글자를 영어로 바꾸는 코드다.
2026년 11월 8일 원재가 영어 설정을 만들고 번역도 모두 넣으라고 했다.
고르면 지금 떠 있는 화면 글자까지 그 자리에서 바뀐다(같은 날 원재가 "바로 바뀜" 을 골랐다).

## 어떻게 바꾸나

코드와 설정 에셋은 한국어 글자를 그대로 쓴다. 화면에 그리기 직전에만 영어로 바꾼다.

- 모든 글상자에 `TextLocalizer` 가 붙는다. 씬을 만드는 도구(`UiSceneBuilder.NewText`)가 붙이고 프리팹으로 만드는 글상자도 따라온다
- `TextLocalizer` 는 TextMeshPro 의 글자 전처리(`ITextPreprocessor`)다. 글상자의 `text` 는 한국어 그대로 두고 그리는 글자만 바꾼다
- 그래서 글자를 읽어 무엇을 가리는 코드와 검사는 언어와 상관없이 같은 한국어 글자를 본다
- 이름 입력칸의 글은 사람이 친 글이라 번역기를 떼어 둔다. 바꿔 그리면 입력 커서 자리가 글과 어긋난다
- 언어가 바뀌면 `Loc.Changed` 가 알리고, 글상자마다 다시 그리게 표시한다. 꺼져 있는 글상자는 켜질 때 영어로 그린다

흐름(`GameFlowController`)이 게임을 켤 때 번역표를 `Loc.SetTable` 로 넣고,
설정을 읽을 때마다 언어 값(드롭다운 차례 0 한국어, 1 English)을 `Loc.SetLanguage` 로 넘긴다.

## 파일 구성

```
Localization/
  Runtime/
    Data/
      GameLanguage.cs        언어. 설정 드롭다운 차례와 같다
      TranslationEntry.cs    번역 한 줄. 한국어 원문과 영어
    Config/
      LocalizationConfig.cs  영어 번역표. ScriptableObject. TSV 를 읽는 법도 여기 있다
    Generation/
      Translator.cs          화면 글자를 번역표로 바꾼다
    UI/
      TextLocalizer.cs       글상자에 붙어 그리기 직전에 바꾼다
    Loc.cs                   지금 언어와 번역표를 한 곳에 둔다
  Text/
    영어.tsv                 번역표 원본. 한국어, 탭, 영어
    빠진 번역.tsv            번역이 빠진 화면 글자. 유니티 검사가 만든다
```

## 번역표

원본은 `Text/영어.tsv` 다. 한 줄에 한국어, 탭, 영어를 적는다. `#` 으로 시작하는 줄은 설명이다.
칸 안의 줄바꿈은 `\n` 으로 적는다.
메뉴 Slot Hero / 번역 가져오기(한 바퀴 다 돌리기에 들어 있다)가 이 파일을 읽어 설정 에셋 `Configs/Localization/LocalizationConfig` 에 담는다.
원본 폴더가 없는 컴퓨터에서는 에셋에 담긴 표를 그대로 쓴다.

| 적는 법 | 뜻 |
| --- | --- |
| `야영` → `Camp` | 원문 그대로 |
| `골드 {0} 필요` → `Needs {0} Gold` | 틀. 자리에 든 글자도 다시 번역한다 |
| `문양 {0}장` → `{0\|symbol\|symbols}` | 값이 1 이면 "1 symbol", 아니면 "3 symbols" |
| `설정 탭\|일반` → `General` | 맥락. 같은 한국어가 화면마다 뜻이 다를 때 쓴다 |
| `한국어` → `=` | 번역하지 않는 글자. 언어 이름과 검사용 이름이다 |

## 찾는 차례

`Translator` 가 한 글자를 바꿀 때 아래 차례로 해 보고 끝까지 번역한 첫 결과를 쓴다.

1. 원문 그대로 있는 줄
2. 앞뒤 빈칸을 뗀 원문
3. 자리(`{0}`)가 있는 틀. 다 번역된 틀 가운데 자리에 든 한글이 가장 적은 틀을 쓴다.
   자리 하나가 줄바꿈, 목록 구분, 여러 문장을 통째로 삼키는 틀은 쓰지 않는다
4. 빈 줄로 나뉜 문단마다, 그다음 줄마다
5. 마침표 뒤에 이어 쓴 문장마다
6. 줄표( — ), 가운뎃점( · ), 쉼표로 늘어놓은 목록이면 낱낱이
7. 글자 꾸밈 표시(`<color>` 같은 것) 사이의 글자마다
8. 끝에 숫자가 붙은 이름("불꽃 8")이면 이름만 번역하고 숫자는 그대로

이어 붙여 만드는 문장("[수은] 을 받는다", "스테이지 1 · 9번째 방")도 틀과 나누기로 번역한다.
그래서 문장을 만드는 코드를 고치지 않아도 된다.

## 맥락

같은 "일반" 이 설정 탭에서는 General, 아이템 등급에서는 Common 이다.
설정 탭 글상자의 `TextLocalizer.Context` 에 "설정 탭" 을 적고 표에 `설정 탭|일반` 줄을 둔다.
맥락 줄이 없으면 원문만으로 찾는다.

## 영어로 긴 글

영어 글이 칸을 넘치는 좁은 칸은 `UiSceneBuilder.ShrinkToFit` 로 넘칠 때만 글자를 줄인다.
지금은 고르기 화면 제목과 프로필 카드의 수정, 삭제 버튼이다. 한국어는 칸에 들어가 크기가 그대로다.
보상 화면의 "오버킬 보상" 은 골드 그림과 겹쳐 영어를 "Overkill" 로 줄였다.

## 내가 정한 것

- 고유 용어 번역은 원재가 맡겼다(2026년 11월 8일). 성소 Sanctum, 야영 Camp, 행상 Merchant, 문양 Symbol, 유물 Relic,
  체력 HP, 태그는 행성 영어 이름(Mercury ~ Pluto)이다. 문양 "수은" 은 태그 수성과 겹치지 않게 Quicksilver 로 했다
- 유물 열 개의 영어 이름은 `RelicConfig` 에 팀원이 적어 둔 영어 이름을 따랐다. Eclips 와 Loaded dice 는 Eclipse, Loaded Dice 로 고쳤다. 흑요석 단검의 Obsidian Knife 는 2026년 11월 8일 원재가 Obsidian Dagger 로 하자고 해 바꿨다
- 몬스터 이름 덤, 더머, 더스트는 소리 나는 대로 Dum, Dummer, Dust 로 적었다
- 언어 이름 "한국어" 는 영어 화면에서도 한국어로 둔다

## 코덱스 검수

2026년 11월 8일 원재가 코덱스에게 번역표 검수를 맡겼다. 코덱스가 고치자고 한 66줄 가운데 64줄을 받았다.
이벤트 문장을 2인칭 현재형으로 맞추고, 최대 보유 수를 Capacity, 등급 비교를 rarer, rarity tier 로 맞췄다.
받지 않은 둘은 "Overkill" 과 "Rusted Gladius" 다. 앞은 보상 화면에서 골드 그림과 겹쳐 줄인 것이고, 뒤는 유물 식별자(`relic_rusted_gladius`)를 따른 것이다.

## 확인

- 순수 로직 검사 `검증/LocalizationTests.cs`. 찾는 차례, 틀, 낱말 수, 맥락, 언어 바꾸기, TSV 읽기, 실제 번역표를 본다
- 유니티 한 바퀴 다 돌리기의 "번역 빠진 글자 찾기" 가 게임 씬 검사와 전투 검사가 띄운 화면 글자,
  설정 에셋과 프리팹의 글자를 모두 번역표에 맞춰 보고 빠진 것을 `Text/빠진 번역.tsv` 에 적는다
- "영어 그림으로 뽑기" 가 확인용 씬을 영어로 바꿔 유니티 프로젝트의 `화면 확인/English` 에 뽑는다
